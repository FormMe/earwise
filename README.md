# 🎧 EarWise — игровой тренажёр музыкального слуха

Веб- и мобильное приложение (PWA + Capacitor) для тренировки слуха: от «выше/ниже» до снятия мелодий и аккордов песен на слух.

## Что внутри

**15 разделов, 64 урока** по нарастающей:
Первые шаги → Мажор/минор → Ступени лада → Интервалы ↑ → Диктант → Интервалы ↓ и гармонические → Пение → Трезвучия → Аккорды в песнях → Ритм → Септаккорды → Минор и хроматика → Лады → Названия нот → Мастерство.

**11 типов упражнений:** выше/ниже, интервалы (↑ ↓ ⇅, с песнями-подсказками), аккорды (15 типов), обращения, лады и гаммы (13), ступени лада с каденцией и разрешением, мелодический диктант, гармонические последовательности (римские цифры), названия нот (с эталоном и абсолютный слух), пение с микрофоном (тюнер), ритм (простукивание с автокомпенсацией задержки).

**Игровые механики:** XP и уровни со званиями, серия дней с заморозками, цель дня, звёзды за уроки, комбо, 21 достижение, «Блиц», «Выживание», «Испытание дня», «Работа над ошибками» (адаптивно по слабым местам), статистика с тепловой картой.

**Свободный тренажёр** с настройкой любого упражнения и **справочник** (интервалы с песнями, аккорды, лады, пианино).

Сравнение с конкурентами — [docs/COMPETITORS.md](docs/COMPETITORS.md).

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm test         # юнит-тесты теории и генераторов
npm run build    # продакшн-сборка в dist/ (PWA, работает офлайн)
```

## Требования

- Браузеры: Chrome / Android WebView 111+, Safari / iOS 16.4+, Firefox 114+.
- Микрофон (упражнения на пение) работает только по HTTPS.
- Обновления: новая версия скачивается в фоне, а применяется кнопкой «Обновить» на главных экранах — урок не прервётся.

## Мобильные приложения

- **Сразу, без магазинов:** откройте сайт на телефоне → «На экран Домой» (iOS) / «Установить» (Android). Приложение работает офлайн.
- **Нативные сборки (Capacitor):** `npm run cap:android` (нужен Android Studio) или `npm run cap:ios` (нужен Xcode на macOS).

## Публикация веб-версии

Синхронизация прогресса: на claude.ai — встроенное облако; в версии на GitHub Pages — секретный Gist твоего аккаунта GitHub (Настройки → Синхронизация, один раз вставить токен с правом `gist`). Между версиями прогресс переносится кодом (Настройки → Перенос кодом).

Workflow `.github/workflows/deploy.yml` проверяет типы и тесты на каждом PR, а при пуше в основную ветку собирает сайт и кладёт его в ветку `gh-pages` — GitHub Pages раздаёт её по адресу https://formme.github.io/earwise/ (Settings → Pages → Source: «Deploy from a branch», `gh-pages`).

Свой домен: Settings → Pages → Custom domain, DNS-запись CNAME на `<user>.github.io`, галочка «Enforce HTTPS». После этого на Android появится полноценная установка приложения (Chrome → «Установить»).

Нативные сборки: `npm run cap:android` / `npm run cap:ios` — скрипт `scripts/cap-permissions.mjs` сам добавляет разрешение на микрофон.

## Структура

```
src/audio      синтез инструментов, движок воспроизведения, распознавание высоты (YIN)
src/theory     ноты, интервалы, аккорды, лады, гармония/голосоведение, мелодии, ритм
src/exercises  генераторы вопросов для всех типов упражнений
src/game       программа обучения, прогресс (zustand + localStorage), достижения, режимы
src/screens    экраны: путь, занятие, итоги, тренажёр, аркада, прогресс, настройки, справочник
```

Горячие клавиши на компьютере: `Пробел`/`R` — повторить, `1–9` — выбрать вариант, `Enter` — дальше, `Backspace` — стереть.
