# Конкуренты и что мы у них взяли

| Приложение | Сильная сторона | Что взяли в EarWise |
|---|---|---|
| **Functional Ear Trainer** (Benbassat) | Ступени лада на фоне каденции, разрешение ноты в тонику | Упражнение «Ступени лада»: каденция I–IV–V–I → нота → после ответа нота «разрешается» поступенно в тонику |
| **EarMaster** | Огромная программа: интервалы, аккорды, диктант, ритм, пение с микрофоном | Линейная программа из 15 разделов, мелодический диктант, ритм (простукивание), пение с оценкой по микрофону |
| **Tenuto / musictheory.net** | Гибко настраиваемые упражнения | Вкладка «Тренажёр»: любой тип упражнения с выбором интервалов/аккордов/ладов/длины |
| **Perfect Ear** | Справочник, песни-подсказки, пение | «Справочник»: интервалы с песнями (в т.ч. русскими), аккорды, лады, пианино |
| **Complete Ear Trainer** | Игровые главы, звёзды за уровни | Звёзды 1–3 за урок (60/75/90%), открытие уроков по цепочке |
| **ToneGym / SoundGym** | Аркадные режимы, рекорды, ежедневные испытания | «Блиц» 60 сек, «Выживание» с 3 жизнями, «Испытание дня» (одинаковое для всех, ×2 XP) |
| **Duolingo** (эталон геймификации) | Путь-змейка, серия дней, цель дня, XP, достижения | Путь с узлами, серия + заморозки, кольцо цели дня, уровни и звания, 21 достижение, конфетти |
| **Chordify / Yousician** | Аккорды в реальных песнях | Раздел «Аккорды в песнях»: функциональные последовательности I–IV–V–vi с голосоведением, заимствованные аккорды |

## Наши фишки сверх конкурентов

- **Адаптивность**: каждый элемент (интервал, ступень, аккорд) имеет свою статистику; слабые выпадают чаще.
- **Работа над ошибками**: одна кнопка — тренировка трёх самых слабых тем.
- **Сравнение на слух после ошибки**: нажимаешь варианты и слышишь, чем твой ответ отличается от правильного.
- **Полностью офлайн**: все инструменты синтезируются в браузере (фортепиано, электропиано, гитара Карплуса–Стронга, орган) — нет загрузки сэмплов.
- **RU/EN**, сольфеджио (До Ре Ми) или буквенные названия.
